# figures/

Static outputs generated by `build_prism_core.py` during geometry construction.
These are committed to the repo as reference — they are not regenerated on every run.

| File | Description |
|------|-------------|
| `core_loading_map.png` | Hex map coloured by assembly type (inner fuel, outer fuel, blankets, reflector, shield) |
| `core_ring_index_map.png` | Same layout annotated with ring number and position index within each ring |
| `core_qr_labels.png` | Same layout annotated with axial (q, r) coordinates |
| `core_assignment.csv` | Machine-readable form: one row per assembly, columns for (q,r), ring, index, universe name |

To regenerate:

```bash
# Q,R coordinate map — no OpenMC or container required
python _gen_qr_map.py

# Ring index and loading maps — generated as a side-effect of build_prism_core.py
./run_openmc.sh python build_prism_core.py core_loadouts/prism_unf_recycle.json
```
